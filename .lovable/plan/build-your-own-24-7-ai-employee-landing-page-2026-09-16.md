# Build Your Own 24/7 AI Employee Landing Page

## Goal
Create a standalone, mobile-first landing page at `/ai-employee` that clearly explains the 4-day program and converts visitors to the configurable payment link.

## What will be built
- Focused hero with program label, offer price, primary/secondary actions, and a realistic AI Employee operations dashboard.
- Problem and opportunity sections using concise beginner-friendly messaging.
- Interactive AI Employee simulation with staged conversation, workflow results, and working Try/Run controls.
- Four-day learning roadmap, build showcase, before/after comparison, audience cards, bonuses, offer, value stack, FAQs, and final action section.
- Persistent mobile enrollment action and smooth in-page navigation.
- A focused CoachRony Academy footer with Privacy, Terms, and Contact links.

## Editable content
Create one configuration file containing the program name, regular and offer prices, dates, class time, bonuses, CTA labels, payment link placeholder, contact information, curriculum, FAQs, and all page copy. Repeated values will be read from this source rather than duplicated.

## Visual direction
- Preserve CoachRony Academy’s dark premium technology-education identity.
- Use a deep navy/black base with restrained electric-blue and cyan accents scoped to this page.
- Use Hind Siliguri and Montserrat, compact cards, subtle translucent surfaces, clear hierarchy, and limited motion.
- Avoid stock imagery, fake urgency, countdowns, income promises, and claims that AI replaces people.

## Technical details
- Add a dedicated TanStack route and small page-specific reusable components.
- Keep the simulation client-side and lightweight; no backend or payment integration will be added.
- `PAYMENT_LINK` remains a clearly configurable placeholder until replaced.
- Give the page unique search/social metadata and verify desktop and mobile rendering plus the demo interaction.
- Hide the standard site navigation and floating actions on this conversion page so only the intended CTA hierarchy remains.
