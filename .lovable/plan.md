# Fix: course detail pages not opening

## Root cause

`src/routes/courses.tsx` is registered at the path `/courses`. In TanStack Router's flat file-based routing, that file becomes the **layout parent** of `courses.$slug.tsx`. Since `courses.tsx`'s `Courses` component does not render `<Outlet />`, the child route matches but nothing from `courses.$slug.tsx` (the sales page) ever shows — the listing renders for every URL under `/courses/*`. Confirmed by navigating to `/courses/ai-free-class` and seeing the Programs/Courses listing instead of the course detail.

## Fix (one-file rename)

Rename `src/routes/courses.tsx` → `src/routes/courses.index.tsx` and update the `createFileRoute` path string from `"/courses"` to `"/courses/"`.

After this:
- `/courses` → renders the listing (`courses.index.tsx`)
- `/courses/ai-free-class` → renders the sales page (`courses.$slug.tsx`)
- `/courses/ai-free-class/checkout` → renders checkout (`courses.$slug.checkout.tsx`)

`src/routeTree.gen.ts` is auto-regenerated by the Vite plugin — no manual edit.

## Verify

Navigate to `/courses/ai-free-class` in the preview; confirm the hero, pricing card, curriculum, FAQ, and Enroll button all render (instead of the 4-card listing).

No other files need changes.
